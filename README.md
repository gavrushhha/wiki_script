# wiki_script

Скрипт для автоматического создания **паспортов информационных систем** в [Яндекс Вики](https://wiki.yandex.ru/) по данным из Excel/ODS.

Для каждой строки таблицы создаётся отдельная **подстраница** под указанной родительской страницей. Заголовок страницы — название системы, содержимое — поля паспорта с жирными подписями.

## Что делает скрипт

1. Читает файл `.xlsx` / `.xlsm` / `.ods` со списком систем.
2. Для каждой строки формирует:
   - **название страницы** — значение столбца «Название системы»;
   - **slug** — на основе Hostname (при совпадении добавляет суффикс с IP / именем / номером);
   - **содержимое** — текст по шаблону паспорта.
3. Создаёт подстраницы через API Яндекс Вики (`POST /v1/pages`).
4. Дополнительно умеет просматривать страницы и поддеревья вики (меню / флаги CLI).

## Формат страницы в вики

```
**Название системы:**

Видеофор

**Описание:**

...

**Заказчик:**

...

**Связанные задачи:**

https://tracker.yandex.ru/...

**Тип системы:**

...

**Статус:**

...

**IP адрес:**

...

**Hostname:**

...

**Открытые порты:**

...
```

## Ожидаемые столбцы в файле

| Столбец в файле | На странице вики |
|-----------------|------------------|
| Название системы | Название системы |
| Описание | Описание |
| Заказчик | Заказчик |
| Задача в трекере / Связанные задачи | Связанные задачи |
| Тип системы | Тип системы |
| Статус | Статус |
| IP адрес / ip | IP адрес |
| Hostname / scan_hostname | Hostname |
| Открытые порты / open_ports | Открытые порты |

Регистр заголовков не важен. Пустые ячейки выводятся как `—`.

pip install requests

## Настройка

В начале `test1.py` заполните:

```python
CLIENT_ID = "..."          # OAuth-приложение Яндекса
CLIENT_SECRET = "..."
ORG_ID = "..."             # или переменная окружения ORG_ID
DEFAULT_PARENT_SLUG = "ntu/.../pasporta-informacionnyx-sistem"
DEFAULT_DATA_FILE = os.path.join(SCRIPT_DIR, "тествики.xlsx")
```

Авторизация:

- через переменную окружения `WIKI_TOKEN` (OAuth-токен), **или**
- интерактивный OAuth (код с `oauth.yandex.ru`).

```bash
export WIKI_TOKEN="y0_..."
export ORG_ID="550622"
```

## Запуск

```bash
# предпросмотр без записи в вики
python3 test1.py --dry-run

# создать подстраницы из файла по умолчанию
python3 test1.py

# указать файл и родительскую страницу
python3 test1.py \
  --file "описание систем.xlsx" \
  --parent-slug ntu/900f18c0fde1/pasporta-informacionnyx-sistem

# интерактивное меню
python3 test1.py --menu
```

### Полезные флаги

| Флаг | Описание |
|------|----------|
| `--dry-run` | Показать, что будет создано, без записи |
| `--file`, `-f` | Путь к Excel/ODS |
| `--parent-slug` | Slug родительской страницы |
| `--url` | Полный URL родительской страницы |
| `--menu`, `-m` | Меню: создание паспортов / просмотр вики |
| `--info` | Информация об одной странице |
| `--descendants`, `-d` | Список потомков страницы |
| `--all-pages`, `-a` | Обзор доступных страниц |

## Как устроена логика создания

1. Строка файла → словарь полей.
2. Заголовок = «Название системы».
3. Slug = `{parent}/{hostname}`; если занят — варианты с IP, названием или `-2`, `-3`, …
4. Контент = подписи `**Поле:**` + значение через пустую строку.
5. Вызов API создания страницы.

При повторном запуске скрипт **создаёт новые страницы** (не обновляет и не пропускает существующие по смыслу записи): при занятости slug подбирается свободный.

## API

Используется [публичный API Яндекс Вики](https://yandex.ru/support/wiki/ru/api-ref/about):

- `GET /v1/pages?slug=...` — получить страницу
- `POST /v1/pages` — создать страницу
- `POST /v1/pages/{id}` — обновить содержимое
- `GET /v1/pages/descendants` — поддерево страниц
